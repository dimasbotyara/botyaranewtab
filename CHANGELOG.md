# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

## [0.2.1] — 2026-11-13

Мобильная адаптация и живучий погодный виджет. Стол для телефона — теперь
первоклассный, а погода больше не молчит, когда провайдер недоступен.

### Добавлено

- **Мобильная адаптация**: новый `static/css/responsive.css` — на планшетах
  и телефонах контент скроллится (`100dvh` вместо `100vh`), часы масштабируются
  под ширину экрана, на телефонах (`≤ 480px`) настройки открываются
  полноэкранным листом с горизонтальной полосой вкладок, виджеты и заметки
  занимают всю ширину, диалоги папок не вылезают за экран.
- **Тач-интерфейс**: редактирование шорткатов по long-press (раньше — только
  правый клик, которого на телефоне нет), тач-таргеты крупнее (тумблеры 48×28,
  слайдеры 26px, точки цветов 30px), кнопка удаления фона на превью больше
  не спрятана за hover, параллакс фона отключается на устройствах без мыши.
- **Погодный виджет говорит**: при ошибке показывает ⚠️ «Не удалось загрузить
  погоду» с кнопкой «⟳ Повторить», тост-уведомление и авто-ретрай
  с бэкоффом (30с → 2 мин). Последние успешные данные сохраняются
  в `localStorage` и показываются при следующем запуске с пометкой «кэш».
  Погода обновляется автоматически раз в 10 минут.
- **Резервные провайдеры погоды**: если `api.open-meteo.com` недоступен
  (в т.ч. заблокирован провайдером), прогноз берётся с `api.met.no` (Yr,
  без ключей), затем с `wttr.in`, с нормализацией в тот же формат. Последний
  удачный провайдер запоминается и пробуется первым — без повторных таймаутов.

### Исправлено

- **Погода не показывалась при сохранённом городе**: ошибка прогноза
  проглатывалась дважды — сервер возвращал `500`, клиент молча игнорировал
  `data.error`, виджет оставался пустым. Теперь любой сбой виден в интерфейсе.
- `round(current.get(...))` падал на JSON-`null` от API (пустой прогноз
  убивал эндпоинт вместо отката на резервный провайдер).
- Город на нулевой долготе (`lon = 0`) отбрасывался проверкой на falsy —
  координаты теперь сравниваются с `null`.
- В `/api/weather` при полном фейле провайдеров — честный `502` вместо `500`.

## [0.2.0] — 2026-11-11

Первый релиз после код-ревью: безопасность, строгая CSP, разбиение стилей,
цветной CLI. Функциональность и настройки не менялись — только надёжность,
защита и структура.

### Безопасность

- **Потеря данных при восстановлении бэкапа**: `restore_backup()` теперь проверяет
  файл (таблицы + `integrity_check`, read-only) до любых изменений, откладывает
  текущую базу в `backups/pre_restore_*.db` и откатывается при ошибке.
  Раньше любой невалидный файл уничтожал базу безвозвратно.
- **Stored XSS**: все пользовательские данные (заголовки шорткатов, группы,
  каунтдауны, мировые часы, история поиска, имена файлов) экранируются через
  `esc()` / `safeColor()` / `safeUrl()` перед вставкой в DOM.
- **`javascript:`-URL и CSS-инъекции**: `PUT /api/shortcuts` валидируется так же,
  как `POST` — не-http(s) схемы, кавычки, нечисловые порты отбрасываются.
- **DoS калькулятором**: `eval` заменён обходом AST с лимитами на длину, глубину,
  показатель степени и величину результата. `9**9**9**9` больше не вешает сервер.
- **CSRF / DNS-rebinding**: небезопасные `/api/*` запросы отбиваются при
  `Sec-Fetch-Site: cross-site`, чужом `Origin` или нелокальном `Host`.
- **SSRF в загрузчике favicon**: только публичные хосты, лимит редиректов и размера,
  тип изображения определяется по сигнатуре файла.
- **Строгая Content-Security-Policy** без `unsafe-inline`/`unsafe-eval`.
- JSON-ошибки API вместо HTML-страниц Flask, `400` вместо `500` на невалидном вводе.

### Исправлено

- Пользовательские шрифты не работали: `@font-face` для загруженных файлов не
  генерировался вообще. Теперь — `/api/fonts/custom.css`.
- Иконки, обои и шрифты отдавались 404 при заданном `BOTYARA_DATA_DIR`
  (сохранялись в одну папку, отдавались из другой).
- Запрос поиска не кодировался: `cat & dog` обрезался до `cat`, `100% скидка`
  ломал URL. `1.5` считался доменом — калькулятор для дробных не работал.
- `manifest.json` ссылался на несуществующие иконки PWA (404 при установке).
- Удаление активного фона оставляло битую ссылку в настройках.
- Service Worker отдавал устаревшие CSS/JS до ручного бампа версии кэша.

### Изменено

- **`static/css/style.css` (1837 строк) разбит на 13 модулей** с сохранением
  порядка каскада; проверено сравнением вычисленных стилей всех элементов.
- Пользовательский CSS отдаётся как настоящая таблица `/api/custom.css`
  вместо инлайнового `<style>` (требование CSP).
- Клиент получает настройки через API, версия рендерится Jinja (`{{ version }}`)
  и доступна по `/api/version`; убран лишний запрос к БД на главной странице.
- `websocket_sync` → `sync_enabled` с миграцией (старое значение сохраняется).
- Консоль: единая палитра (янтарный градиент + бирюза) в `console_ui.py`,
  градиентный баннер в `run.py`.
- `.github/workflows`: настоящий прогон `pytest` (без `||`-фолбэка),
  `compileall` и `node --check` для JS.

### Добавлено

- 72 теста (`tests/`): API, безопасность, CSP, миграции, версия.
- `requirements-dev.txt`, `pytest.ini`, `CHANGELOG.md`, `docs/SECURITY_FIXES.md`.
- Иконки PWA 192/512 + maskable.
- Переменные окружения `BOTYARA_ALLOWED_HOSTS` и `BOTYARA_FRAME_ANCESTORS`.
